# BloomCare Homepage

This is a standalone React + Vite implementation of the BloomCare public homepage mockup.

## Run

1. Open this folder in VS Code.
2. Run `npm install`
3. Run `npm run dev`
4. Open the local Vite URL shown in the terminal.

## Notes

- The homepage is one continuous scrollable page.
- Bootstrap is used for responsive layout and FAQ accordion.
- Custom CSS creates the BloomCare visual identity.
- The buttons and navigation are demonstration/front-end interactions.
- The contact form has client-side validation.
- Medical consultation, calculations, authentication, payments and chatbot functionality are intentionally not implemented yet.
- Lifestyle images currently use remote Unsplash URLs. Replace them with local project assets later if desired.
